# 节奏类 — 策划阶段专项指南

本文档覆盖节奏类内容在策划阶段的专项规则，包括卡点视频、舞蹈、音乐可视化、节奏剪辑、变装、运镜卡点等以"节奏和律动"为核心的品类。

---

## 节奏类的核心驱动：节拍到镜头的映射

节奏类内容的策划本质是**数学映射**——把音乐的节拍结构转化为镜头序列。

### 基础公式

```
镜头时长 = (X拍 × 60) / BPM
```

其中 X 是每个镜头占据的拍数。

### BPM-镜头时长对照表

| BPM | 1拍 | 2拍 | 4拍 | 8拍 | 典型风格 |
|-----|-----|-----|-----|-----|---------|
| 70 | 0.86s | 1.71s | 3.43s | 6.86s | 慢舞、氛围 |
| 90 | 0.67s | 1.33s | 2.67s | 5.33s | R&B卡点 |
| 110 | 0.55s | 1.09s | 2.18s | 4.36s | 变装、走秀 |
| 128 | 0.47s | 0.94s | 1.88s | 3.75s | 主流舞蹈卡点 |
| 140 | 0.43s | 0.86s | 1.71s | 3.43s | 快舞、高能卡点 |
| 170 | 0.35s | 0.71s | 1.41s | 2.82s | 极速燃向 |

## 五大节奏公式

### 1. 经典卡点（最常用）

```
强拍 = 换镜头 | 弱拍 = 过渡 | Drop = 定格+闪切
```

每个强拍切换画面，弱拍用转场填充。Drop 部分在强拍加入 0.3s 定格效果。

### 2. 速度梯度

```
慢(每4拍换) → 中(每2拍换) → 快(每1拍换) → 极快(每半拍换) → 定格(收束)
```

适合 Build Up → Drop 结构的音乐。

### 3. 段落对比

```
A段(每4拍换+暖色调) → B段(每2拍换+冷色调) → A段(每4拍换+暖色调加强)
```

主歌-副歌结构的视觉化。两个段落的色调、剪辑密度形成鲜明对比。

### 4. 动作同步

```
动作起始 = 节拍1 | 动作发展 = 节拍2-3 | 动作完成 = 节拍4
```

每个动作周期精确对应一个小节（4拍）。适合舞蹈/变装/动作展示。

### 5. 波形可视化

```
低频 = 大画面/慢运动 | 高频 = 小画面/快运动 | 振幅 = 画面缩放
```

画面变化跟随音乐频谱。适合音乐可视化/频谱类内容。

## 舞蹈视频镜头分配

| 景别 | 占比 | 用途 |
|------|------|------|
| **全景** | 30% | 展示完整舞蹈动作、队形变化 |
| **中景** | 40% | 主力叙事景别，展示上半身+手臂动作 |
| **近景/特写** | 20% | 面部表情、手部细节、标志性动作 |
| **面部特写** | 10% | 关键节拍的表情强调 |

### 卡点变装公式

```
正常造型 → 遮挡画面 → 强拍揭示新造型 → 展示新造型 → 准备下一个
```

| 步骤 | 拍位 | 动作 |
|------|------|------|
| 正常展示 | 1-3拍 | 展示当前造型，动作自然 |
| 遮挡 | 第4拍 | 用手/衣服/转场遮挡画面 |
| 揭示 | 第1拍(下一小节强拍) | 新造型出现，配合闪光/音效 |
| 展示 | 2-4拍 | 自信展示新造型，pose定格 |

## 音乐特征选择指南

| 音乐特征 | 适合的节奏类目 | 原因 |
|---------|--------------|------|
| **清晰鼓点（Kick/Snare）** | 卡点视频、变装 | 节拍起点明确，容易对齐 |
| **Build Up + Drop** | 高能卡点、燃向 | 天然的速度梯度结构 |
| **循环旋律（Loop）** | 舞蹈翻跳 | 节奏稳定，方便编排重复动作 |
| **变速/变拍** | 高级卡点、炫技 | 在节奏变化处做剪辑创意 |
| **有人声段落** | 字幕卡点 | 每句歌词=一个字幕动画触发点 |

## 策划检查清单

### 节拍分析
- [ ] BPM 已确定？每拍时长已计算？
- [ ] 强拍/弱拍/Drop 位置已标记？
- [ ] 总拍数和可用镜头数是否匹配？

### 镜头分配
- [ ] 强拍分配了最有冲击力的画面？
- [ ] 舞蹈类：全景/中景/特写比例 ≈ 30:40:30？
- [ ] 变装类：揭秘拍位的服装切换设计好了？

### 视觉节奏
- [ ] 相邻镜头的色调/亮度是否有对比（避免"一锅粥"）？
- [ ] 速度变化是否有明确的结构（如慢→快→定格）？
- [ ] Drop 部分是否有"爆点"设计（定格/闪切/特效文字）？

### 字幕节奏
- [ ] 字幕是否计划启用逐词高亮？
- [ ] 强拍是否计划叠加特效文字？
- [ ] 歌词/关键词的字幕动画是否与节拍对齐？
