# 叙事类 — 策划阶段专项指南

本文档覆盖叙事类内容在策划阶段的专项规则，包括科幻短片、微电影、剧情向、故事片等以"讲故事"为核心的品类。

---

## 叙事类的核心驱动：三幕结构

叙事类内容的结构设计决定了最终成片的感染力。策划阶段的核心产出是一份**分镜脚本**。

### 时长-幕段对照表

| 幕段 | 30s 版本 | 60s 版本 | 120s 版本 | 功能 |
|------|---------|---------|----------|------|
| **第一幕：建立** | 0-6s | 0-12s | 0-25s | 引入角色、建立世界、暗示冲突 |
| **第二幕：对抗** | 6-22s | 12-45s | 25-90s | 冲突升级、角色挣扎、转折点 |
| **第三幕：解决** | 22-30s | 45-60s | 90-120s | 高潮、收束、余韵 |

### 五大故事公式

| 公式 | 核心机制 | 适用时长 | 示例 |
|------|---------|---------|------|
| **时间压力** | 倒计时+障碍累积 | 30-60s | 最后10秒拆除炸弹，每次剪错一根线 |
| **认知反转** | 预设→颠覆→新视角 | 15-45s | 主角追凶到最后发现自己在镜子里 |
| **角色弧光** | 从A状态→B状态的转变 | 60-120s | 冷漠的医生→为病人冒险的主角 |
| **层层揭示** | 每一层揭示更大的真相 | 45-90s | 以为是车祸→其实是谋杀→其实是... |
| **日常塌陷** | 日常突然被打破 | 15-30s | 普通上班日→手机收到自己死亡的新闻 |

## 分镜语法

### 镜头组合规律

叙事类每个叙事节拍对应一组镜头：

| 节拍类型 | 镜头组合 | 时长 |
|---------|---------|------|
| **建立-发现** | 全景(建立空间) → 中景(角色反应) → 特写(关键物件/表情) | 3-5s |
| **张力升级** | 中景→近景→特写(逐级收紧) 或 双人镜头→单人镜头→越肩镜头 | 2-4s |
| **揭示** | 特写(细节) → 拉远(揭示全貌) 或 快速匹配切(两次同一构图不同内容) | 1-3s |
| **反应镜头** | 事件画面→角色面部特写→角色动作 | 2-4s |
| **交叉剪辑** | A场景/B场景/A场景/B场景(越来越短) | 4-8s |

### 颜色叙事规则

| 叙事效果 | 色彩策略 |
|---------|---------|
| **闪回/记忆** | 褪色 40% + 暖黄 tint，或黑白+颗粒 |
| **幻觉/梦境** | 色调偏移（正常→冷蓝/暖洋红）, gamma 曲线扭曲 |
| **情绪低点→高点** | 去饱和→饱和，暗调→亮调 |
| **时间流逝** | 同一场景不同时间的色温变化（白天暖→夜晚冷） |
| **角色转变** | 角色服装/环境色调随弧线渐变 |

## 对话规则

1. **展示，不要说**：能用画面传达的绝不用台词。"我恨你" → 角色撕掉合影
2. **潜台词 > 明台词**：角色说的话和真正意思之间的差距=戏剧张力
3. **沉默也是对话**：最有力的台词往往是沉默之后的下一句
4. **短促有力**：抖音叙事类单句不超过 80 字（45s 以内总台词量）

### 独白/旁白策略

| 用法 | 效果 | 示例 |
|------|------|------|
| **开场独白** | 建立世界观/角色状态 | "他们说这个城市不会下雪。他们错了。" |
| **结尾独白** | 点题/余韵 | 配合最后一个画面淡出 |
| **反差旁白** | 画面叙事+旁白评价形成反讽 | 画面：温馨的晚餐。旁白："这是她最后一次见他。" |

## 策划检查清单

### 结构检查
- [ ] 三幕完整且比例合理？（建立:对抗:解决 ≈ 1:3:1）
- [ ] 第一幕前 3 秒有 hook？（悬念/冲突/反常画面）
- [ ] 第二幕有至少一个转折点？
- [ ] 第三幕有明确的"收束感"？（call back、完成弧线、留白）

### 效率检查
- [ ] 每个镜头都在推进故事？（没有"风景填充"）
- [ ] 每句台词都承载信息或情绪？（没有废话）
- [ ] 每个场景都有明确的存在理由？

### 节奏检查
- [ ] 紧张-释放-紧张-释放的呼吸感？
- [ ] 高潮前的铺垫足够但不过度？
- [ ] 反转/揭示的时刻足够有力？
