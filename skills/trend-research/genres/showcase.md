# 展示类 — 调研阶段专项指南

本文档覆盖展示类内容在趋势调研阶段的专项规则，包括 Vlog、旅行记录、美食制作过程、手工艺制作、日常记录、沉浸式体验等以"呈现过程/氛围"为核心的品类。

---

## 展示类的核心驱动：体验传达

与情绪驱动的内容不同，展示类内容的爆款逻辑由 **体验传达** 决定。调研时关注的不是"什么情绪火"，而是"什么体验当前最稀缺/最令人向往"。

| 价值维度 | 说明 |
|---------|------|
| **沉浸感** | 让观众感觉"我在现场"的程度 |
| **向往感** | "我也想要/也想去/也想吃"的欲望激发 |
| **过程美感** | 从起始到完成的视觉享受（烹饪/制作/整理） |
| **信息密度** | 画面中蕴含的可被感知的细节数量 |
| **真实质感** | 非摆拍的、有呼吸感的真实记录 vs 精致但冰冷的制作 |

### 体验传达判断标准

调研时评估一个展示方向是否值得做：

- **感官刺激强度**：视觉/听觉/嗅觉（通过画面暗示）的刺激是否强烈？
- **场景稀缺度**：这个地点/场景是否大众难以接触到的？（稀缺=流量）
- **过程价值**："做出来之前的过程"本身是否有观赏价值？
- **共鸣密度**：这个场景/体验是否能让多数人产生"我也有过"的联想？

## 爆款模式识别

展示类内容的传播力来源于以下驱动力：

| 驱动力 | 触发方式 | 用户行为 |
|--------|---------|---------|
| **沉浸感** | 第一人称/有呼吸感的镜头语言 | 完播 + 反复观看（当白噪音） |
| **向往感** | 展示理想生活/旅行/美食的巅峰体验 | 收藏 + 转发（"以后要去"） |
| **过程愉悦** | 有序的过程展示（烹饪/收纳/制作） | 反复观看（解压）+ 收藏（想学） |
| **信息价值** | 隐藏的好去处/宝藏小店/私藏清单 | 收藏（打卡清单）+ 评论求地址 |
| **偷窥快感** | 展示别人不轻易展示的生活侧面 | 完播 + 评论（"这是在哪"） |

### 展示类爆款公式

```
爆款展示 = 高感官密度 + 真实质感 + 信息增量
```

- **高感官密度**：画面中的色彩/纹理/光线/声音构成丰富的感官体验
- **真实质感**：有瑕疵的、有呼吸感的、不完美但真实的内容建立信任感
- **信息增量**：观众看完获得了有价值的信息（餐厅名/位置/做法/路线）

## 展示品类调研框架

调研时用此矩阵分析展示类内容的趋势：

| 品类 | 核心吸引力 | 爆款要素 | 制作门槛 |
|------|-----------|---------|---------|
| **旅行Vlog** | 视觉奇观 + 文化差异 | 小众目的地、当地人视角、意外事件 | 中（需要旅行条件） |
| **美食过程** | 食材变化 + 感官刺激 | 特写、声音（切菜/沸腾）、材料处理技巧 | 低（普通厨房即可） |
| **日常记录** | 共鸣 + 理想化日常 | 氛围感、光影、节奏感、配乐 | 低（手机可拍） |
| **手工艺/DIY** | 创造过程 + 成品反差 | 步骤演示、材料说明、成品展示 | 中（需要手艺/材料） |
| **收纳/整理** | 秩序感 + 视觉舒适 | 前后对比、分类展示、收纳技巧 | 低（有空间即可） |
| **自然/风景** | 视觉奇观 + 情绪舒缓 | 特殊天气、黄金时刻、无人机视角 | 高（设备+天气条件） |
| **宠物记录** | 可爱 + 行为趣味 | 互动、特殊行为、拟人化 | 低（有宠物即可） |

## 选题评估标准

在通用评估框架基础上，展示类需额外评估：

| 评估维度 | 关注点 |
|---------|--------|
| **场景可获得性** | 用户能否实际到达/复现这个场景？ |
| **视觉独特性** | 这个场景/过程是否已有大量同类内容？区分度在哪里？ |
| **感官丰富度** | 画面+声音能否构成完整的感官体验？（注意背景音/环境音） |
| **信息附加值** | 观众看完能带走什么？（地点/菜谱/路线/技巧） |
| **制作成本** | 是否需要特殊设备（无人机/稳定器/收音）？ |

### 制作难度分级

| 级数 | 设备要求 | 适用场景 |
|------|---------|---------|
| **手机级** | 一部手机 + 自然光 | 日常记录、简单美食、收纳 |
| **基础级** | 手机 + 补光灯 + 领夹麦 | 室内Vlog、美食制作、手工艺 |
| **进阶级** | 相机 + 三脚架 + 麦克风 | 旅行Vlog、室外拍摄、夜景 |
| **专业级** | 无人机/稳定器/多机位 | 风景航拍、专业美食片、旅行大片 |

## 调研关注点

### 场景/地点调研

- 搜索目标城市的"宝藏店铺""小众景点""拍照好看的地方"
- 关注小红书上的探店/打卡类内容——高收藏率的帖子是信号
- 追踪季节性场景（秋天的银杏、冬天的雪景、夏天的夜市）
- 收集"同城"标签下的热门地点（附近就能拍，制作成本低）

### 视觉风格调研

- 搜索目标品类标杆账号的调色风格（电影感/日系/暖调/冷调）
- 收集高赞内容的画面构成方式（构图/运镜/景别选择）
- 关注"氛围感"相关的热门标签和滤镜趋势
- 分析爆款Vlog的前5秒画面——是什么画面留住了观众？

### 声音设计调研

- 收集展示类内容常用的环境音素材（雨声/Jazz/厨房声/翻书声）
- 搜索适合展示类内容的BGM类型（松弛感/治愈系/轻快节奏）
- 关注ASMR类元素的使用趋势（咀嚼声、切菜声、雨声）
- 分析BGM与画面节奏的配合方式（音乐卡点 vs 氛围铺底）

### 形式创新调研

- 搜索展示类内容的创新形式（分屏对比、延时摄影、镜面反射）
- 关注跨品类融合趋势（美食+故事、旅行+科普）
- 收集"过程全记录"类内容的节奏控制方式（加速/跳剪/打断点）

## 平台差异

| 维度 | 抖音 | 小红书/XHS |
|------|------|-----------|
| **内容偏好** | 沉浸式过程、前后反差、视觉冲击 | 氛围感、细节图、地点标注、清单体 |
| **时长控制** | 15-45s（黄金时段：30s左右） | 图文为主，视频1-3min可接受 |
| **核心指标** | 完播率 + 重播率 | 收藏率（"先码住"）+ 互动 |
| **变现路径** | 广告带货 | 探店合作/品牌植入/引流私域 |
| **标签策略** | 场景类标签（#沉浸式 #治愈系） | 地点类标签（#上海探店）+品类标签 |
