# 叙事类 — 调研阶段专项指南

本文档覆盖叙事类内容在趋势调研阶段的专项规则，包括科幻短片、微电影、剧情类、悬疑故事、情感短剧等以"讲故事"为核心的品类。

---

## 叙事类的核心驱动：故事结构

与情绪驱动的内容不同，叙事类内容的爆款逻辑由 **故事结构** 决定。调研时关注的不是"什么情绪火"，而是"什么故事模式当前有流量"。

| 结构维度 | 说明 |
|---------|------|
| **钩子结构** | 前3秒用悬念/冲突/反常建立观看契约 |
| **弧光结构** | 角色从A到B的转变轨迹（成长/堕落/觉醒） |
| **反转结构** | 信息差驱动的认知颠覆（叙事诡计） |
| **闭环结构** | 开头元素在结尾call back，制造完成感 |
| **留白结构** | 只给线索不给答案，诱导评论区推理 |

### 结构质量判断标准

调研时评估一个故事结构是否值得做：

- **信息差强度**：观众知道的和角色知道的差距越大，代入感越强
- **转折密度**：60秒内的有效转折数量（非平铺直叙）
- **hook锐度**：前3秒能否建立"必须看下去"的好奇心
- **评论区引爆力**：结尾是否天然催生"我没看懂""我猜到了"的讨论

## 爆款模式识别

叙事类内容的传播力来源于以下驱动力：

| 驱动力 | 触发方式 | 用户行为 |
|--------|---------|---------|
| **悬念** | 信息不对称 + 关键信息延迟释放 | 完播 + 追系列 |
| **认知颠覆** | 预设被推翻（叙诡/视角转换） | 反复观看 + 转发（"细思极恐"） |
| **情感投射** | 角色困境触发共情（代入感） | 评论（"如果我是他…"）+ 收藏 |
| **世界构建** | 设定本身足够新奇/完整 | 求续集 + 二创 |

### 叙事类爆款公式

```
爆款叙事 = 高密度信息差 + 精确节奏控制 + 强收束
```

- **高密度信息差**：每一帧都在释放信息或埋设伏笔，没有废镜头
- **精确节奏控制**：紧张—释放—紧张—释放的节律，像呼吸一样
- **强收束**：结尾让之前所有信息重新排列，产生"原来如此"的顿悟感

## 叙事模式速查表

调研时识别当前平台上流行的叙事模式（非穷尽，持续更新）：

| 模式 | 典型时长 | 核心机制 | 平台偏好 |
|------|---------|---------|---------|
| **三秒反转** | 15-30s | 极度压缩的起承转合 | 抖音（完播率驱动） |
| **叙事诡计** | 30-60s | 视角切换/时间线误导 | 双平台通用 |
| **微连续剧** | 3-8集×60s | 每集结尾留钩子，追剧效应 | 抖音（系列流量加成） |
| **设定展示** | 15-30s | 不展开故事，只展示世界观 | 小红书（收藏驱动） |
| **情感短剧** | 45-90s | 强情绪弧线+高代入感 | 双平台通用 |
| **伪纪录片** | 30-60s | 镜头语言营造真实感 | 抖音（沉浸感） |
| **多线叙事** | 60-90s | 多条线索最后交汇 | 内容质量要求高 |

## 选题评估标准

在通用评估框架基础上，叙事类需额外评估：

| 评估维度 | 关注点 |
|---------|--------|
| **Hook锐度** | 前3秒能否制造"不问不快"的悬念？能否用一句话概括钩子？ |
| **反转可设计性** | 这个话题是否有天然的信息差可以利用？还是需要强行编造？ |
| **系列延展性** | 这个设定能否支撑多集内容？还是只能做一集？ |
| **制作可执行性** | 场景/道具/演员是否在制作能力范围内？ |
| **结构新鲜度** | 这种叙事模式是否已被做烂？评论区是否出现"又来了"？ |

### 可执行性分级

| 级别 | 说明 | 适用用户 |
|------|------|---------|
| **纯对白型** | 不需要场景切换，靠台词和运镜完成叙事 | 新手创作者 |
| **单场景型** | 单一场景+多机位+靠表演和剪辑 | 有基础设备者 |
| **多场景型** | 需要多个实景或简单布景 | 有团队支持者 |
| **视效型** | 需要特效/合成/绿幕 | 有后期能力者 |

## 调研关注点

### 叙事模式调研

- 搜索当前平台热门短剧/剧情类内容的叙事结构
- 分析爆款剧情号的评论区："猜到了""没猜到""求续集"是结构有效性的信号
- 追踪跨媒介叙事热梗（从电视剧/小说/游戏改编而来的叙事模式）
- 注意叙事时长的平台偏好变化（抖音叙事内容在变长/变短？）

### 视觉参考调研

- 搜索该题材类型的标杆画面风格（赛博朋克的色调、悬疑片的布光）
- 收集同类题材作品的运镜方式和剪辑节奏
- 关注低成本但视觉效果好的制作技巧（手机如何拍出电影感）

### 选角/角色调研

- 搜索该角色的外貌/气质参考图
- 分析同类内容的角色设定类型（强势女主、草根逆袭、反套路人设）
- 关注演员选择的可用性（素人可执行 vs 需要专业演员）

### 声音设计调研

- 搜索适合叙事氛围的背景音乐（悬疑配乐、史诗感BGM）
- 收集叙事类内容常用的音效库（转场音、氛围音、冲击音）
- 关注AI配音的接受度和使用方式

## 平台差异

| 维度 | 抖音 | 小红书/XHS |
|------|------|-----------|
| **叙事时长** | 15-60s为主，系列可延展 | 图文叙事为主，短视频为辅 |
| **内容偏好** | 反转、悬疑、微连续剧 | 设定展示、情感短篇、脑洞 |
| **发布策略** | 系列化发布（多集连更吃流量） | 单篇精品（图文叙事更易收藏） |
| **评论区价值** | 评论催更 = 流量信号 | 讨论剧情细节 = 收藏率信号 |
| **配乐要求** | 热门BGM加成大 | 配乐权重低于内容质量 |

## 调研检查清单

- [ ] 当前平台上流行的叙事模式有哪些？（逆向分析3-5个爆款）
- [ ] 最火的3个剧情类账号在用哪种结构？（三秒反转/叙诡/连续剧...）
- [ ] 这些爆款内容的前3秒使用了什么类型的钩子？
- [ ] 评论区的核心讨论点是什么？（猜剧情？求续集？争结局？）
- [ ] 该叙事模式在两条平台上的表现差异如何？
- [ ] 该题材的制作成本是否在用户能力范围内？
- [ ] 有没有可以借势的跨界热梗（电影/游戏/社会事件）？
- [ ] 有没有适合该题材的热门BGM或配乐风格？
