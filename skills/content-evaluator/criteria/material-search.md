# 素材搜索阶段评审标准（material-search）

> 适用：videoSource=search 的作品在调研前的素材搜索步骤。该步骤的目标是为分镜
> 预置可用的实拍/素材库候选，不是产出最终素材。

## 评审维度

### 1. 搜索覆盖与查询质量 (search_coverage)
- 是否围绕主题拆出了多组有效查询词（而非单一宽泛词）？
- 是否使用了可用的搜索通道（$web_search / 素材库 API），而非 curl 抓站硬啃？
- 搜索结果是否记录了来源与关键元数据（时长/分辨率/授权）？

**评分标准：**
- 9-10: 多组查询、来源与元数据完整、命中率高
- 7-8: 查询有效但覆盖略窄或元数据不全
- 5-6: 单一查询、结果稀少但未尝试改写查询
- 1-4: 大量无效抓取（curl 404/反爬）仍不调整策略

### 2. 候选相关性 (relevance)
- 候选素材与主题的语义相关性是否经过筛选（而非全量堆放）？
- 是否剔除了明显不可用项（水印/低清/题材不符）？

**评分标准：**
- 9-10: 候选精炼且每条有选用理由
- 7-8: 基本相关，少量噪声
- 5-6: 相关性参差，筛选痕迹不明显
- 1-4: 与主题明显不符或未做任何筛选

### 3. 可用性核实 (usability)
- 候选链接/文件是否验证可下载、可读取？
- 下载后的文件是否通过基本校验（非 0 字节、可 probe）？

**评分标准：**
- 9-10: 全部候选经验证可用
- 7-8: 大部分验证，个别未验
- 5-6: 只下载未校验
- 1-4: 候选不可达/文件损坏未察觉

### 4. 产出留痕 (deliverable_trace)
- 是否产出结构化清单（JSON/MD），字段足以支撑后续 plan 阶段直接引用？
- 清单路径是否明确（workDir 内可查）？

**评分标准：**
- 9-10: 结构化清单完整、路径明确
- 7-8: 有清单但字段略欠
- 5-6: 只有零散记录
- 1-4: 无留痕，后续阶段无从引用
