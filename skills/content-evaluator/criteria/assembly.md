# 合成阶段评审标准

## 评审维度

### 1. 技术参数 (technical_params)
检查方法：使用 ffprobe 检查最终输出

```bash
# 必须运行的检查命令
ffprobe -v error -show_entries format=duration,size -show_entries stream=width,height,r_frame_rate,codec_name,codec_type,sample_rate,channels -of json output/final.mp4
```

**检查项：**
- 分辨率：竖屏1080x1920，横屏1920x1080
- 编码：H.264 (libx264)
- 帧率：≥24fps（推荐30fps）
- 音频：AAC，44100Hz，**立体声（channels=2，单声道不达标）**
- 时长：符合方案规划（±20%误差范围内）
- 文件大小：合理范围内（不超过100MB/分钟）
- 是否有音频轨（必须有！）
- **output/quality-report.json 的检测对象必须是 output/final.mp4 本身**（看 videoPath 字段），且出具时间晚于 final.mp4 最后修改时间；针对模板分段/中间产物的 QC 报告一律视为无效

**评分标准：**
- 9-10: 所有技术参数完美达标
- 7-8: 基本达标，个别参数可优化
- 5-6: 有技术问题但不影响播放
- 1-4: 严重技术问题（无法播放、无音频、分辨率错误）

### 2. 剪辑节奏 (editing_rhythm)
- 镜头切换频率是否与内容类型匹配？
- 是否有不合理的长静止镜头？
- Hook部分（前3秒）的节奏是否紧凑？
- 结尾是否有适当的收束？

**评分标准：**
- 9-10: 节奏感极佳，完播率预期高
- 7-8: 节奏合理，没有明显的拖沓
- 5-6: 有部分段落节奏失衡
- 1-4: 整体节奏混乱或极度拖沓

### 3. 音画协调 (audio_visual_sync)
评审依据：content-assembly/modules/audio-spec.md（评审前必读）

- **响度实测（必做）**：`ffmpeg -i final.mp4 -af ebur128=peak=true -f null -` 实测 I 值命中 -16~-14 LUFS、TP ≤ -1dBTP？
- BGM 是否盖过人声（抽开头/中段/结尾三段核对人声可懂度）？BGM 是否做了响度锚定（I=-34）或闪避？
- SFX 音效层是否存在且克制（≤8 处、对齐画面事件）？还是全片只有干巴巴的旁白+BGM？
- BGM 风格与内容氛围匹配？淡入淡出处理？开头 1 秒内是否有声音？
- 卡点视频的画面切换是否与节拍对齐？有无突兀音频断裂或杂音？

**评分标准：**
- 9-10: 响度实测达标、三层混音清晰（人声/SFX/BGM 各就其位）、有 ducking 或等效处理
- 7-8: 音画协调、响度达标，SFX 层缺失但听感不单调
- 5-6: BGM 局部盖过人声，或响度偏离平台区间
- 1-4: 音画严重不协调/无 BGM/响度严重超标（外放刺耳或听不清人声）

### 4. 字幕质量 (subtitle_quality)
- 字幕是否与画面同步？
- 字幕位置是否合理（不遮挡主体）？
- **单行字数是否超标（中文 ≤15 字/行）？抽 3 个长句时间点截帧核对：字幕不得超出画面左右边界（部分 ffmpeg 构建的 libass 无 CJK 断词，长行不换行会直接出框）**
- 字幕是否清晰可读（大小、颜色、描边）？
- 内容是否准确、无错别字？
- 每行字数是否合理（15-20字以内）？

**评分标准：**
- 9-10: 字幕专业精美，增强了内容表达
- 7-8: 字幕清晰可读，时间同步
- 5-6: 字幕存在小问题（位置不佳、偶有不同步）
- 1-4: 字幕严重影响观看体验

### 5. 调色一致性 (color_grading)
- 全片色调是否统一？
- 是否有应用调色（不是原始色调）？
- 调色是否适合内容类型和平台？
- 不同片段之间的色彩过渡是否平滑？

**评分标准：**
- 9-10: 调色专业，统一的视觉风格
- 7-8: 有基础调色，色调基本统一
- 5-6: 调色不一致或无调色
- 1-4: 色调混乱，各片段色彩差异巨大

### 6. 发布文案 (publish_text)
- 标题是否吸引人（含关键词、有吸引力）？
- 正文是否完整（含平台特定格式）？
- 标签/话题是否合理（数量、相关性）？
- 发布时间建议是否合理？

**评分标准：**
- 9-10: 文案专业，SEO优化到位，话题精准
- 7-8: 文案完整，基本优化
- 5-6: 文案存在明显缺项
- 1-4: 缺少发布文案或质量极差

## Critical 问题示例
- 最终视频无音频轨
- 最终视频无法播放（编码错误）
- **output/final.mp4 不存在（评审时成片尚未产出，必须直接 fail——不得对分段产物评审放行）**
- **quality-report.json 缺失、检测对象不是 final.mp4、或出具时间早于 final.mp4 最后修改时间**
- **音轨为单声道或采样率非 44.1/48kHz（平台要求立体声）**
- 画面出现黑边或黑屏段落
- 时长严重偏离方案（误差>50%）
- 缺少发布文案（publish-text.md不存在）
- 视频中出现了不属于此内容的画面（素材错误）
- BGM 盖过人声（人声不可懂）或响度实测严重偏离 -16~-14 LUFS
- 开头 1 秒静音（播放事故）
- 静态数据卡/图表镜头出现肉眼可见抖动（裸 zoompan 亚像素抖动）
- **字幕单行超过 15 个汉字 / 超出画面左右边界（抽帧可见文字出框）**
- **结构/流程/逻辑类镜头全用静态文字卡应付，未使用 code-scene 程序化动画（分镜含此类镜头时）**

### 7. 模板还原度 (template_fidelity)（2026-08-19 新增,"假窗口"事故)
> 适用:作品绑定了视频模板(works.template_id 非空)。未绑定模板的作品跳过本维度,不打分。

- 模板声明的视频/图片变量槽位(type:video/image)是否全部被真实素材填充?
- **抽帧核对模板窗口区:窗口内必须是真实视频/图片画面,禁止空框、纯色块、"提示文字"占位**(如窗口里只有一行说明文字=假窗口,critical)
- 模板标题卡/要点卡的文字内容是否来自本片主题(而非模板默认示例值)?
- 混排的非模板分段(code-scene/图表/实拍)是否与模板风格协调(同色系/同字体)?

**评分标准:**
- 9-10: 槽位全部真实填充,模板版式还原,混排风格统一
- 7-8: 槽位填充但个别分段风格略跳
- 5-6: 部分槽位空转或模板文字残留默认值
- 1-4: 窗口空框/占位文字冒充内容/模板形同虚设

**Critical 追加:**
- **绑定模板的视频/图片槽位未被真实素材填充(空窗口、色块占位、提示文字占位)**
