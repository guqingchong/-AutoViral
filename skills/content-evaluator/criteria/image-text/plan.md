# 图文作品·策划阶段评审标准(image-text/plan)

> **规则分级(2026-08-28 批次6.1)**：【硬性】= 机器可判/明确阈值,违反即 fail;【软性】= 需判断,作评分依据。
> 图文作品不产出视频——**禁止要求 final.mp4、字幕、音轨、时长等视频产物**。

## 评审维度

### 1. 选题与钩子 (hook) 【软性·需判断】
- 封面标题是否 3 秒抓住滑动中的用户(痛点/悬念/反常识)?
- 标题 ≤20 字,含关键词,极限词(最/第一/唯一/首个)必须有"之一"限定 【硬性】

### 2. 卡片结构 (card_structure) 【硬性·机器可判】
- 卡片数量规划:封面 1 张 + 内容卡 ≥4 张 + 结尾卡(CTA/引导)1 张
- 每张卡信息量克制:主文案 ≤60 字,一个卡片只讲一个要点
- 卡序逻辑:痛点/悬念 → 拆解/论证 → 结论/行动

### 3. 视觉规划 (visual_plan) 【软性·需判断】
- 封面图概念明确(人物/场景/对比),搜图或生图关键词具体可执行
- 全组视觉风格统一(同一配色/版式体系,绑定模板时严格按模板)

### 4. 文案与合规 (copy_compliance) 【硬性·机器可判】
- 口播/正文文案完整,第一人称或品牌口吻一致
- 无平台违禁词/绝对化用语(无"之一"限定的极限词)
- 标签 5-6 个,与内容强相关

## Critical 问题示例
- 卡片结构缺失(无封面/无内容卡规划)
- 标题极限词无"之一"限定
- 规划中出现视频产物要求(final.mp4/字幕/音轨)——图文作品无此产物
