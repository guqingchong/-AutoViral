# 内容规划与配图探查阶段评审标准（图文作品 · 流水线 v2）

> **适用**：pipeline_version=2 图文（image-text）作品的 `plan-assets` 阶段。
> 评审对象：plan/plan.md（卡片规划）+ assets/script.json + assets/registry.json + assets/material-candidates.md。

## 评审维度

### 1. 卡片规划结构 (card_structure) 【硬性·机器可判】 min_ai: 7
- 卡片规划必须含：封面卡（标题+钩子）+ 内容卡（每卡一个论点）+ 结尾卡（引导互动）；
- 每卡文字量 ≤200 字（超出无法排版）；
- 标题 ≤20 字，含关键词；极限词（最/第一/唯一/首个）必须有"之一"限定。

**评分标准：**
- 9-10: 结构完整，节奏清晰，字数合规
- 7-8: 结构完整，个别卡片超字数
- 5-6: 缺封面或结尾卡
- 1-4: 无卡片结构意识

### 2. 内容溯源与口径一致 (script_fidelity) 【硬性·机器可判】 min_ai: 8
- 卡片文案必须能溯源到 article.md 的对应 section（script.json 带 source_section）；
- 文章没有的事实进卡片 → fail；待核断言进卡片正文（非披露场景）→ fail。

**评分标准：** 同视频版（逐句可溯源为优，脱节/自造事实为 fail）。

### 3. 配图探查覆盖 (exploration_coverage) 【硬性·机器可判】 min_ai: 7
- 每卡配图需求必须在 registry.json 登记（来源 URL/授权/tier）；
- 只登记元数据，禁止下载（下载属图片生成阶段）；
- 配图需求与卡片内容语义相关的检索证据（查询组记录）。

**评分标准：**
- 9-10: 逐卡覆盖，元数据完整
- 7-8: 覆盖完整，个别缺字段
- 5-6: 部分卡片无登记
- 1-4: 大面积无登记

### 4. 文案与合规 (copy_compliance) 【硬性·机器可判】 min_ai: 8
- 无极限词、无虚假承诺、无违规导向；
- 引用数据必须标注来源（卡片脚注或文案内）。

**评分标准：**
- 9-10: 合规干净，来源标注完整
- 7-8: 基本合规，个别标注缺失
- 5-6: 多处来源未标注
- 1-4: 含极限词/虚假承诺

## Critical 问题示例
- 卡片文案含文章之外的新造事实
- 配图需求未登记即进入图片生成
