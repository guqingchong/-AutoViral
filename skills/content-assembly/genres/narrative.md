# 叙事类 — 合成阶段专项指南

本文档覆盖叙事（Narrative）品类在内容合成阶段的剪辑节奏、BGM 策略、音效使用和转场规则，适用于科幻短片、微电影、剧情短片、情感故事等。

---

## 叙事类剪辑节奏

目标：让观众沉浸于故事，而非意识到剪辑的存在。节奏服务于叙事弧线。

### 三幕式节奏框架

| 幕段 | 氛围 | 剪辑节奏 | 单镜头时长 |
|------|------|---------|-----------|
| **开场/引子**（0-15%） | 建立情绪、地点、氛围 | 慢入，每个镜头 3-6 秒 | 推轨/横移建立空间 |
| **展开/冲突**（15-70%） | 由缓到急，悬念累积 | 加速趋势：4s → 2s | 越紧迫切得越频繁 |
| **高潮/转折**（70-90%） | 情绪顶峰 | 快切或突然延长停顿 | 节奏变化制造冲击 |
| **结尾/余韵**（90-100%） | 沉淀 | 放缓，每个镜头 4-6 秒 | 留白，给观众消化空间 |

### 核心剪辑原则

- **看不见的剪辑（Invisible Cut）**：转场应当让观众注意不到剪辑的存在
- **30 度规则**：同一主体的连续两个镜头，机位角度至少差 30 度
- **呼吸感**：每个冲突段落之后留 1-2 秒"呼吸时间"
- **节奏递增原则**：随着剧情推进，镜头越来越短、切换越来越快
- **极端相反——突然放慢**：在高潮前突然切到 3-5 秒的长镜头

### 特殊手法

| 手法 | 用法 | 效果 |
|------|------|------|
| **J Cut** | 画面切之前声音先入 | 预告感，自然过渡到新场景 |
| **L Cut** | 画面切之后声音延续 | 保持连贯，淡入新场景 |
| **蒙太奇** | 快切系列短镜头 | 浓缩时间，表达情绪变化 |
| **匹配切** | 利用构图/动作/形状相似性切换 | 视觉优雅过渡 |
| **fade to black** | 场景结束处渐黑 | 明确的时间/场景跳转 |

## 叙事类转场策略

| 转场 | 使用时机 | 叙事功能 |
|------|---------|---------|
| `fade`（交叉淡化） | 角色回忆、梦境、情感过度的段落间 | 柔和连接两个情绪世界 |
| `fadeblack`（经黑屏） | 场景切换、时间跳跃、章节分界 | 明确的段落感 |
| `dissolve` | 慢节奏的情感时刻 | 画面叠加产生诗意 |
| 直切（无转场） | 对话、动作连续性场景 | 保持叙事节奏 |

**转场时长：**
- 对话/动作连续场景：0s（直切）
- 情感过渡：0.5-1.0s（fade/dissolve）
- 场景/时间切换：1.0-2.0s（fadeblack）
- 蒙太奇段落：0.2-0.3s fast dissolve

**禁止使用的转场：** `wipeleft`/`wiperight`、`circlecrop`、`rectcrop`、`smoothleft`/`smoothright`

## 叙事类字幕

使用 `caption_generate.py` 的 `--style cinematic` 预设。

```bash
python3 skills/content-assembly/scripts/caption_generate.py \
  --input video.mp4 --output subtitles.ass \
  --style cinematic --language zh \
  --font-size 48 --highlight-color "#F5E6C8" \
  --base-color "#CCCCCC" --stroke-width 2 \
  --max-words 6 --position bottom
```

### 叙事类字幕规范

- **字号偏小**：44-52px（不喧宾夺主，让画面说话）
- **颜色柔和**：文字米白（#F0E6D0），禁用纯白
- **居下对齐**：`y=80%` 位置
- **每行限制**：5-8 个中文字符
- **无对话时绝对不加字幕**：氛围靠画面和音乐传达

## 音乐与音效设计

### BGM 分层策略

| 层级 | 内容 | 音量 | 作用 |
|------|------|------|------|
| 环境音 | 风声、城市嗡鸣、室内氛围 | 15-25% | 建立空间真实感 |
| 背景音乐 | 情绪配乐（无歌词优先） | 25-40% | 情绪定向 |
| 音效/拟音 | 脚步声、开门、呼吸 | 50-70% | 增强真实感 |
| 对白 | 演员/配音 | 100% | 叙事核心 |

### BGM 选择规则

1. **无歌词优先**：纯器乐/氛围音乐不干扰对白
2. **情绪曲线匹配**：每一段 BGM 的情绪起伏必须与故事弧线吻合
3. **变奏过渡**：场景转折点用音乐变奏（非突然切歌）过渡
4. **静音是最有力的音效**：关键台词后留 1-2 秒"空白"

## 调色风格

| 风格 | 适用故事类型 | 调色参数 |
|------|-------------|---------|
| **暖调怀旧** | 青春、回忆、温情 | `brightness=0.02:contrast=0.95:saturation=0.85:gamma=1.1` |
| **冷调科幻** | 科幻、悬疑、未来 | `brightness=-0.02:contrast=1.15:saturation=0.70:gamma=0.95` |
| **褪色纪实** | 剧情片、现实题材 | `brightness=0.0:contrast=1.05:saturation=0.50:gamma=1.05` |
| **高对比电影感** | 正剧、史诗 | `brightness=-0.03:contrast=1.25:saturation=0.90:gamma=0.90` |

## 平台导出设置

### 抖音 9:16 (1080x1920)

```bash
ffmpeg -i final-graded.mp4 \
  -c:v libx264 -preset slow -crf 18 \
  -c:a aac -b:a 192k -ar 48000 \
  -r 30 -profile:v high -level:v 4.1 \
  -pix_fmt yuv420p \
  -y output/douyin-narrative.mp4
```

- CRF 18（叙事类追求画质）
- 音频 192k 保证环境音细节不损失

### 小红书 3:4 (1080x1440)

```bash
ffmpeg -i final-graded.mp4 \
  -vf "crop=1080:1440:0:(ih-1440)/2" \
  -c:v libx264 -preset slow -crf 18 \
  -c:a aac -b:a 192k -ar 48000 -r 30 \
  -y output/xhs-narrative.mp4
```

## 质量检查清单

1. **叙事弧线完整**：开场→冲突→高潮→结局，情绪曲线是否连贯？
2. **节奏递增**：是否前慢后快？高潮部分镜头的切换频率是否高于开场？
3. **转场不显眼**：所有转场是否服务于叙事？是否有不该出现的炫技转场？
4. **字幕不抢戏**：字号是否偏小？颜色是否柔和？
5. **环境音存在**：全片是否有持续的环境音？没有"真空"段落？
6. **BGM 无歌词冲突**：如果有歌词，歌词情绪是否与画面情绪一致？
7. **对白清晰**：BGM 是否压过了对白？
8. **调色统一**：全片色调是否一致？
9. **画幅正确**：抖音 9:16？小红书 3:4？无黑边？
10. **CRF <= 18**：叙事类内容画质优先

**情绪自检**：这条成品能让观众产生什么情绪？
- 科幻/悬疑：紧张、好奇、震撼
- 微电影：感动、共情、沉思
- 剧情短片：意外、共鸣、回味
