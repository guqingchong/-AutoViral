# 节奏类 — 合成阶段专项指南

本文档覆盖节奏（Rhythm）品类在内容合成阶段的剪辑规则，适用于卡点视频、舞蹈、音乐可视化、时装变装、运镜剪映等内容类型。

**核心原则：画面切换必须精确锁定节拍，误差不超过 1 帧（~33ms at 30fps）。**

---

## 节奏类核心方法论

节奏类是唯一一种"BGM 决定剪辑"的内容类型。整个剪辑流程围绕音乐节拍展开。

### 工作流概述

```
选曲 → 节拍检测 → 按拍组织镜头 → 帧级对齐 → 字幕落重音 → 导出
```

**必须先读以下模块：**
- `modules/beat-sync.md` — 卡点剪辑完整方法论
- `modules/music-search.md` — 按 BPM/情绪搜索下载音乐

**必须调用的脚本（禁止手写内联代码）：**
- `scripts/beat-sync/detect_beats.py` — 分析音乐节拍
- `scripts/beat-sync/beat_sync_edit.py` — 一键卡点剪辑
- `scripts/caption_generate.py` — 字幕逐词高亮

## 节奏类剪辑节奏

### 节拍结构理解

| 术语 | 定义 | 在卡点视频中的意义 |
|------|------|------------------|
| BPM | 每分钟节拍数 | 决定镜头切换的频率 |
| 强拍（Downbeat） | 每个小节的第一拍 | 最重要的切换点——放最有冲击力的画面 |
| 弱拍（Offbeat） | 小节中非重音拍 | 可做次级切换或过渡画面 |
| 半拍 | 两拍之间的半个节拍 | 快速切镜或闪切 |

### BPM 与镜头时长对照表

| BPM | 每拍时长 | 建议每拍镜头数 | 典型内容 |
|-----|---------|--------------|---------|
| 60-80 | 750-1000ms | 1-2 拍/镜头 | 慢舞、氛围卡点 |
| 80-110 | 545-750ms | 1 拍/镜头 | 变装、时装走秀 |
| 110-130 | 461-545ms | 1 拍/镜头 | 主流舞蹈卡点 |
| 130-150 | 400-461ms | 每拍 1-2 个镜头 | 快舞、活力卡点 |
| 150-180 | 333-400ms | 每拍 2 个镜头 | 极速卡点、燃向 |

### 剪辑节奏模板

**4 拍结构（最常用，适合变装/转场/舞蹈）：**

```
拍1（强拍）：新造型/新场景 — 定场画面
拍2（弱拍）：动作延续 — 过渡
拍3（弱拍）：进一步展现 — 细节
拍4（强拍）：Pose / 定帧 / 冲击 — 爆点
```

**8 拍结构（适合完整舞蹈段落）：**

```
第1-2拍：起始动作（全景，全身）
第3-4拍：动作发展（中景）
第5-6拍：高潮动作（快速切镜或特写）
第7拍：停顿/定格（0.3-0.5s，制造对比）
第8拍：落地/收尾（最强冲击力画面）
```

## 节奏类转场策略

| 转场 | 适用拍位 | 效果 | 时长 |
|------|---------|------|------|
| 直切 | 每一拍的基础切换 | 干净利落 | 0s |
| `fade` | 过渡拍（弱拍） | 柔和过渡到下一画面 | 0.2s |
| `dissolve` | 双拍连续渐变 | 画面变换效果 | 0.3s |
| `slideleft`/`slideright` | 强拍 | 方向性动感 | 0.2s |
| `distance` | 强拍（变装类） | 视觉冲击，镜头拉近 | 0.3s |
| `radial` | 第 4 拍/第 8 拍 | 炫技开场或结尾 | 0.3s |
| 定格（Freeze Frame） | 强拍后第1个半拍 | 制造节奏"顿感" | 0.3-0.5s |
| 闪切（Flash Frame） | 半拍位置 | 极短画面（1-2帧），冲击力 | 0.05s |

**转场时长硬性规则：**
- 所有转场时长必须 <= 拍长的一半（例如 120 BPM = 500ms/拍，转场最多 250ms）
- 强拍转场 0.2-0.3s，弱拍用直切或 0.1-0.2s 淡化

## 卡点剪辑执行流程

### 第一步：节拍检测

```bash
python3 skills/content-assembly/scripts/beat-sync/detect_beats.py your-music.mp3 -o beats.json
```

### 第二步：一键卡点（推荐）

```bash
python3 skills/content-assembly/scripts/beat-sync/beat_sync_edit.py \
  --video clip-01.mp4 clip-02.mp4 clip-03.mp4 \
  --music your-music.mp3 \
  --output final-beat-synced.mp4 \
  --style dramatic
```

### 第三步：手动精调（需要帧级控制时）

参照 `modules/beat-sync.md` 中的手动流程，用 xfade 在精确时间点对齐。

### 第四步：定格效果

在强拍位置插入 0.3-0.5s 定格，制造节奏变化。

## 节奏类字幕

使用 `caption_generate.py` 的 `--style douyin-highlight` 预设。

```bash
python3 skills/content-assembly/scripts/caption_generate.py \
  --input concat.mp4 --output subtitles.ass \
  --style douyin-highlight --language zh \
  --font-size 64 --highlight-color "#FE2C55" \
  --base-color "#FFFFFF" --stroke-width 4 \
  --max-words 8 --position center
```

### 节奏类字幕规范

- **字号超大**：60-72px，占屏幕 1/3 高度不夸张
- **逐词高亮必开**：每个词随着节拍亮起，创造"字幕舞蹈"效果
- **高亮色用品牌色**：#FE2C55（TikTok red）或 #FFD700（金色）
- **居中对齐**：`position center`
- **每行 4-6 字**：短促有力
- **节奏点叠加大字**：在强拍位置叠加大号文字

## 音乐与音效设计

### 音乐选曲规则

1. **明确的节拍**：BPM 稳定、鼓点清晰
2. **热门 BGM 优先**：抖音热歌有算法流量加成
3. **有"drop"（高潮段）**：结构清晰的歌曲天然适合卡点
4. **全曲时长 15-40s**：短视频卡点不宜太长

### BGM 音量策略

- 卡点视频中 BGM 是绝对主角：**音量 80-100%**
- 如果有环境音或人声：降低至 20-30%，BGM 保持 70-80%

### 音效在节拍上的使用

| 音效 | 拍位 | 作用 |
|------|------|------|
| Whoosh | 转场前 0.1s | 为切换做"空气铺垫" |
| Hit/Impact | 强拍 | 强化画面冲击力 |
| 上升音（Riser） | 第 7 拍到第 8 拍 | 在 Drop 前制造张力 |
| 玻璃碎裂 / 快门声 | 变装完成的瞬间 | 标注"新造型出现" |

## 调色风格

| 风格 | 适用 | 参数 |
|------|------|------|
| **高对比高饱和** | 舞蹈、燃向卡点 | `brightness=0.0:contrast=1.20:saturation=1.30:gamma=0.92` |
| **褪色冷酷** | 时装变装、高级感 | `brightness=-0.02:contrast=1.15:saturation=0.60:gamma=0.90` |
| **霓虹幻想** | 夜间、赛博、派对 | `brightness=-0.05:contrast=1.30:saturation=1.50:gamma=0.88` |

## 平台导出设置

### 抖音 9:16 (1080x1920)

```bash
ffmpeg -i final-graded.mp4 \
  -c:v libx264 -preset fast -crf 20 \
  -c:a aac -b:a 256k -ar 48000 -r 30 \
  -profile:v high -level:v 4.1 -pix_fmt yuv420p \
  -movflags +faststart \
  -y output/douyin-rhythm.mp4
```

- CRF 20：节奏类需要画面细节（变装、舞蹈动作）
- 音频 256k：音乐是核心，高码率保证音质
- `-movflags +faststart`：支持流式播放（卡点视频常被反复观看）

## 质量检查清单

1. **画面精确卡拍**：每个画面切换点是否落在节拍 +/- 1 帧范围内？
2. **强拍画面最强**：每个强拍是否分配了最有冲击力的画面/动作？
3. **转场不超拍长一半**：所有转场时长是否 <= 拍长/2？
4. **Drop 部分冲击力够**：高潮/变装部分是否比其他部分有更强视觉冲击？
5. **定格/顿感有效**：是否有在关键位置用定格制造节奏变化？
6. **字幕逐词高亮**：字幕是否启用了 `douyin-highlight` 样式？
7. **BGM 音量足够**：卡点视频 BGM 音量是否在 80-100%？
8. **音频码率 >= 256k**：音乐是核心体验
9. **调色统一高冲击**：全片色彩是否按卡点风格预设统一？
10. **画幅正确**：抖音 9:16？小红书 3:4？

**终极验证**：关掉声音看一遍——如果无声时画面节奏仍然能够被感知，那么这个视频成功。卡点视频的本质是"看得见的节奏"。
