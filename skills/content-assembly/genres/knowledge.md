# 知识类 — 合成阶段专项指南

本文档覆盖知识（Knowledge）品类在内容合成阶段的剪辑节奏、BGM 策略和排版规范，适用于教程、测评、科普、开箱、学习方法等内容类型。

---

## 知识类剪辑节奏

目标：信息密度高但消化门槛低。每个知识点一个视觉单元，观众可以随时暂停回顾。

### 章节式节奏框架

| 阶段 | 时间占比 | 节奏 | 剪辑要点 |
|------|---------|------|---------|
| **Hook（注意力钩子）** | 前 15% | 快节奏，0.5-2s 快切 | 抛出问题/反常识结论/预告亮点 |
| **核心内容** | 60-70% | 稳定 3-5s 镜头，配合 B-roll | 每个知识点一个"画面+字幕"单位 |
| **总结/CTA** | 最后 15-20% | 放缓，关键结论停留 4-6s | 总结要点，引导关注/收藏 |

### 核心剪辑原则

- **信息密度优先**：剪掉所有废话、犹豫、空档。每个画面必须传递至少一个信息点
- **视觉化每句话**：每个知识点要有对应的画面（B-roll、图表、动画、实物演示）
- **"三秒原则"**：如果前 3 秒没有建立起信息价值预期，观众会划走
- **停顿不剪——观众消化时间**：在关键信息输出后留 1-2 秒停顿
- **章节标记清晰**：内容切换时用明显的视觉标记（标题卡、分隔画面、转场）
- **跳切（Jump Cut）大量使用**：精简口语中的停顿和重复，知识类用激进阈值 0.4s

## 知识类转场策略

| 转场 | 使用时机 | 功能 |
|------|---------|------|
| `fade` | 知识点内部段落过渡 | 柔和分隔，保持流畅 |
| `fadeblack` | 大章节之间 | 明确的章节分水岭 |
| `wipeleft`/`wiperight` | 清单/列表递进 | "下一条"的视觉暗示 |
| 直切 | 同知识点内连续讲解 | 维持信息密度 |
| 标题卡过渡 | 用文字卡片画面作为转场 | 知识点命名，便于回顾 |

**转场时长：**
- 同知识点段落：0.3s fade
- 章节切换：0.8-1.0s fadeblack
- 标题卡：1.5-2.5s（停留时间让观众读完）

## 知识类字幕

使用 `caption_generate.py` 的 `--style minimal` 预设。

```bash
python3 skills/content-assembly/scripts/caption_generate.py \
  --input concat.mp4 --output subtitles.ass \
  --style minimal --language zh \
  --font-size 56 --highlight-color "#FF6B35" \
  --base-color "#FFFFFF" --stroke-width 3 \
  --max-words 10 --position bottom
```

### 知识类字幕规范

- **字号偏大**：56-64px（信息类必须清晰易读）
- **颜色高对比**：白色正文 + 橙色/蓝色关键词高亮
- **顶部可叠加关键词**：同时有底部语音字幕 + 顶部关键词
- **每行 10-15 字**：让观众一次读完一个完整信息单元
- **关键词高亮必开**：`--highlight-color` 标记术语/数字/人名
- **数字/数据务必用文字标出**：如果画面图表中有数字，要在顶部叠加大字标注

### 标题卡制作

标题卡是知识类最强的转场工具。每个大章节目录必做：

```bash
ffmpeg -f lavfi -i "color=c=#1A1A2E:s=1080x1920:d=3" \
  -vf "drawtext=text='为什么是神经网络':fontsize=72:fontcolor=white:x=(w-text_w)/2:y=(h-text_h)/2-60:fontfile=~/.autoviral/fonts/NotoSansCJK-Bold.ttf, \
       drawtext=text='与传统机器学习的关键区别':fontsize=40:fontcolor=#FF6B35:x=(w-text_w)/2:y=(h-text_h)/2+40:fontfile=~/.autoviral/fonts/NotoSansCJK-Regular.ttf" \
  -c:v libx264 -preset fast -crf 18 -y chapter-title.mp4
```

## 音乐与音效设计

### BGM 规则

知识类 BGM 的核心功能是**维持注意力**而非渲染情绪。

| 内容子类型 | BGM 风格 | BPM | 音量 |
|-----------|---------|-----|------|
| 教程/操作 | Lo-fi、轻电子、无歌词 | 80-100 | 15-20% |
| 深度科普 | 氛围/环境音乐、极简钢琴 | 60-80 | 15-20% |
| 测评 | 轻快电子、Upbeat | 100-120 | 20-25% |
| 学习方法 | 白噪音、Lo-fi、钢琴 | 60-80 | 12-18% |

**核心规则：**
1. **BGM 不能抢注意力**：音量始终 15-25%
2. **无歌词**：歌词会与解说词争夺语音带宽
3. **旋律简单**：太复杂的旋律会分散注意力
4. **段落切换时音乐不切换**：知识类内容中 BGM 保持一条 track 贯穿全片
5. **音效用于强调**：在出现关键结论/数据时，加一个"叮"或"啵"音效

## 质量检查清单

1. **Hook 前 3 秒抓人**：是否在 0-3 秒内建立了信息价值预期？
2. **章节结构清晰**：不看画面只看标题卡和顶部标签，能否理解全片结构？
3. **每个知识点都有画面**：有没有超过 5 秒的"纯人脸讲话"画面？
4. **数据可视化**：关键数字是否在画面上以大字号标出？
5. **字幕清晰**：字号是否 56+？关键词是否有高亮色？
6. **BGM 不抢戏**：音量是否在 15-20%？是否有歌词干扰？
7. **冗余被剪干净**：跳切是否去掉了所有停顿和重复？
8. **BGM 音量不压人声**：旁白与 BGM 的比例是否 100:18 左右？
9. **画幅正确**：抖音 9:16？小红书 3:4？
10. **文件大小合理**：CRF 22 左右

**情绪自检**：
- 教程：成就感（"看完我学会了"）
- 科普：好奇满足（"原来是这样！"）
- 测评：信任感（"这个博主靠谱"）
