# 展示类 — 合成阶段专项指南

本文档覆盖展示（Showcase）品类在内容合成阶段的剪辑节奏、BGM 策略和风格导向，适用于 Vlog、旅行记录、美食制作过程、运动记录、ASMR、手工制作等内容类型。

---

## 展示类剪辑节奏

目标：让观众感觉"身临其境"而非"被塞信息"。节奏服务于沉浸感，保留真实的时空流动感。

### 沉浸式节奏框架

| 内容子类型 | 镜头平均时长 | 切换频率 | 节奏感觉 |
|-----------|-------------|---------|---------|
| **旅行/户外** | 4-8s（航拍可 8-15s） | 低 | 悠然，探索感 |
| **美食制作** | 3-6s（过程)、1-2s（特写/成品） | 中低 | 流畅，伴随感 |
| **Vlog 日常** | 3-5s（叙事)、2-3s（过渡/环境） | 中 | 代入感，真实感 |
| **手工/制作** | 4-10s（关键过程慢放) | 低 | 专注，解压感 |
| **ASMR / 解压** | 6-15s（一个完整动作周期) | 很低 | 沉浸，疗愈 |

### 核心剪辑原则

- **保留"空气感"**：不要剪掉所有沉默。环境音、动作过程中的自然停顿是沉浸感的关键
- **不跳切**：展示类严格避免跳切。所有切换必须通过转场或动作连续性实现
- **动作连续性剪辑（Action Cut）**：在动作过程中切换机位，保持动作完整
- **慢放增强细节**：关键动作慢放 0.5-0.75x，让观众看细节
- **节奏稳定不加速**：全过程节奏一致，不需要"从慢到快"的递增

### 镜头排序策略

展示类按"空间顺序"或"时间顺序"排列：

```
# 旅行 Vlog 时间流：
起床氛围(2s) → 出门风景(4s) → 路上抓拍(3s) → 到达地点(5s) → 过程记录(8s) → 成品/发现(4s) → 反应瞬间(3s)

# 美食制作时间流：
食材全景(3s) → 处理过程(6s) → 烹饪过程(8s) → 出锅慢动作(3s) → 成品特写(5s) → 品尝反应(4s)
```

## 展示类转场策略

| 转场 | 使用频率 | 使用时机 | 效果 |
|------|---------|---------|------|
| `fade` | 常用 | 段落之间、时间跳跃 | 柔和，日常感 |
| `dissolve` | 常用 | 相似画面间过渡 | 诗意连接 |
| `smoothleft`/`smoothright` | 中等 | 从一个地点移动到另一地点 | 丝滑前进感 |
| `fadeblack` | 少用 | 长时间跳跃（如"第二天"） | 时间流逝 |
| `distance` | 偶尔 | 从环境到细节的聚焦 | 注意力引导 |
| 直切 | 最低频率 | 快速动作切换 | 对比/省略 |

**转场时长：**
- 日常段落过渡：0.5-0.8s（fade/dissolve/smooth）
- 长时间跳跃：1.0-1.5s（fadeblack）
- 动作连续性切换：0s（直切，但必须动接动）

**禁止使用的转场：** `slideleft`/`slideright`、`wipeleft`/`wiperight`、`circlecrop`/`rectcrop`

## 展示类字幕

展示类字幕优先级最低——能用画面传达就不用文字。

```bash
python3 skills/content-assembly/scripts/caption_generate.py \
  --input concat.mp4 --output subtitles.ass \
  --style xhs-soft --language zh \
  --font-size 44 --highlight-color "#D4A574" \
  --base-color "#CCCCCC" --stroke-width 1 \
  --max-words 6 --position bottom
```

### 展示类字幕规范

- **字号偏小**：40-48px，半透明（不挡画面）
- **颜色淡雅**：浅灰/米色（#D4C5A9），禁用白亮色
- **仅做辅助标记**：地点名称、食材名称、动作描述
- **不需要语音转字幕**：展示类常常没有台词
- **文案式短句**：不是完整句子，而是标签式短语

### 位置标注

旅行/美食内容在屏幕左上角标注当前地点/食物名称：

```bash
ffmpeg -i subtitled.mp4 \
  -vf "drawtext=text='. 稻城亚丁':fontsize=32:fontcolor=#D4A574@0.8:x=40:y=40:fontfile=~/.autoviral/fonts/NotoSansCJK-Regular.ttf" \
  -c:v libx264 -crf 20 -c:a copy -y tagged.mp4
```

## 音乐与音效设计

### BGM 选择矩阵

| 画面风格 | 推荐 BGM 类型 | BPM | 示例关键词 |
|---------|--------------|-----|-----------|
| 旅行/户外 | 阳光民谣、世界音乐、轻电子 | 90-120 | acoustic, ukulele, world |
| 美食制作 | 轻爵士、Lo-fi、Neo Soul | 70-100 | chillhop, bossa nova |
| Vlog 日常 | 独立流行、电子 Funk | 100-130 | indie pop, funky |
| 手工/创造 | 氛围电子、极简钢琴 | 60-90 | ambient, cinematic |
| 解压/ASMR | 纯环境声（原声) | - | 保留原始声音 |

### BGM 规则

1. **BGM 是主角，不是背景**：展示类中 BGM 的权重可以和画面持平
2. **全曲贯穿**：一首 BGM 贯穿全片，不切换
3. **节奏和画面动作匹配**：BGM 的节奏感应该和画面中动作的节奏一致
4. **人声段落 BGM 自动降音**：用 sidechaincompress 在有人声时自动降低 BGM
5. **环境音保留**：原始环境音必须保留——油锅的滋滋声、脚步声、街道喧闹声

**千万不要替换掉原始音频**——环境音是展示类内容沉浸感的根基。

## 调色风格

| 风格 | 子类型 | 参数 |
|------|--------|------|
| **暖阳** | 旅行、自然、Vlog | `brightness=0.03:contrast=0.98:saturation=1.10:gamma=1.05` |
| **美食** | 美食、烹饪 | `brightness=0.02:contrast=1.05:saturation=1.20:gamma=1.02` |
| **胶片** | 日常 Vlog、复古 | `brightness=-0.02:contrast=1.10:saturation=0.75:gamma=0.96` |
| **清新** | 手工、布置、静物 | `brightness=0.05:contrast=0.95:saturation=1.05:gamma=1.08` |

## 平台导出设置

### 抖音 9:16 (1080x1920)

```bash
ffmpeg -i final-graded.mp4 \
  -c:v libx264 -preset medium -crf 20 \
  -c:a aac -b:a 192k -ar 48000 -r 30 \
  -profile:v high -level:v 4.1 -pix_fmt yuv420p \
  -y output/douyin-showcase.mp4
```

- CRF 20：展示类对画质有要求（旅行风景/美食特写需要细节）
- 音频 192k：环境音细节需要高码率保留

## 质量检查清单

1. **沉浸感**：看完是否有"看完很舒服"的感觉？
2. **环境音存在**：原始环境音是否被错误替换或删除了？
3. **BGM 匹配画面情绪**：BGM 的风格是否和画面氛围一致？
4. **转场不炫技**：所有转场是否"顺滑不显眼"？
5. **字幕不挡画面**：字幕字号是否偏小（40-48px）？颜色是否柔和半透明？
6. **动作连续性**：每个切换是否有动作连续性支撑？没有"跳切"出现？
7. **地点/事物标注**：关键位置/食材/物品有没有标注清楚？
8. **色彩风格统一**：全片调色是否保持一致的风格预设？
9. **画幅正确**：抖音 9:16？小红书 3:4？无黑边？
10. **CRF 20**：画质足够好

**情绪自检**：
- 旅行 Vlog：向往、放松、羡慕（"我也想去"）
- 美食制作：食欲、解压、满足
- Vlog 日常：共鸣、陪伴、温暖
- 手工/制作：专注感、成就感、敬畏
