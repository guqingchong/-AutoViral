# 声音设计规范模块

"高级感"的一半来自声音。本模块是全部音频处理的强制规范：响度标准、三层混音参数、SFX 音效层、闪避。**合成阶段凡涉及音频，必须执行本模块。**

---

## 一、平台响度标准（出片目标）

| 平台 | 整体响度 | True Peak |
|------|---------|-----------|
| 抖音/快手/小红书/视频号 | **-16 ~ -14 LUFS**（移动端外放优先，宁可略响） | ≤ -1 dBTP |
| B站/YouTube | -14 LUFS | ≤ -1 dBTP |

成片导出前必须测量（不符合则重混）：

```bash
# 响度测量(读 I 值=integrated LUFS 和 LRA)
ffmpeg -i final.mp4 -af ebur128=peak=true -f null - 2>&1 | tail -12
```

## 二、三层混音层级（强制参数）

声音的优先级铁律：**人声永远清晰可懂，其余一切都为人声让路。**

| 层 | 相对电平 | 处理 |
|----|---------|------|
| **人声/旁白** | 锚点，`loudnorm=I=-15:TP=-1.5:LRA=11` | 先定人声，再混其他 |
| **SFX 音效** | 比人声低 6-12dB（冲击点可瞬时逼近人声） | 只在信息点/转场出现，见第三节 |
| **BGM 音乐** | 比人声低约 19dB，`loudnorm=I=-34:TP=-3:LRA=11` | 能量强的曲风再降 3dB；永不与人声竞争 |

参考混音命令（旁白+BGM 两轨）：

```bash
ffmpeg -i video.mp4 -i bgm.mp3 -filter_complex \
  "[0:a]loudnorm=I=-15:TP=-1.5:LRA=11[v];[1:a]loudnorm=I=-34:TP=-3:LRA=11[bgm];\
   [v][bgm]amix=inputs=2:duration=first:dropout_transition=2[a]" \
  -map 0:v -map "[a]" -c:v copy -y out.mp4
```

**闪避（ducking，条件具备时优先）**：BGM 在旁白出现时自动衰减 3-6dB，旁白间隙回弹——大片感的来源之一：

```bash
# sidechain: 以人声为侧链信号压缩 BGM
[bgm][voice]sidechaincompress=threshold=0.02:ratio=6:attack=20:release=400[ducked]
```

## 三、SFX 音效层（目前全片最容易缺失的高级感来源）

纯口播+BGM 的听感是"平"的。专业短视频在以下位置铺音效（**音量克制，低人声 6-12dB，出现即走**）：

| 位置 | 音效类型 | 作用 |
|------|---------|------|
| Hook 首帧 | whoosh/冲击音（hit） | 抓住注意力，配合画面切入 |
| 数据卡/图表出现 | 轻微 "pop"/"ding" | 提示"看这里"，强化信息点 |
| 转场 | whoosh/swish | 润滑剪切，掩盖硬切 |
| 金句/大字卡 | 低沉 boom/心跳 | 情绪重音 |
| 结尾 CTA | 上挑短音（riser 收尾） | 收束感 |

**规则**：全片 SFX ≤8 处，宁少勿滥；音效必须对齐画面事件帧（误差 <0.1s）；无合适音效时宁可不加，禁止用噪音凑数。

**获取渠道**（按优先级）：
1. 公共素材库音效类资产（/api/shared-assets 中 audio/sfx 分类）
2. yt-dlp 免版权音效库（如 Pixabay SFX / Freesound 免版权条目）
3. 禁止：ffmpeg 合成正弦波/噪声充当音效（静默降质）

---

## 四、混音自检清单（成片前必过）

- [ ] `ebur128` 实测整体响度命中平台区间（-16~-14 LUFS）、TP ≤ -1dB？
- [ ] 旁白全程可懂度：抽 3 段（开头/中段/结尾）人声是否始终清晰压过 BGM？
- [ ] BGM 有无盖过人声的段落（尤其高潮/鼓点段）？
- [ ] SFX 是否对齐画面事件、数量克制（≤8 处）？
- [ ] 开头 1s 内是否有声音（静音开头=播放事故）？结尾是否淡出（afade）而非戛然而止？

## 五、参考基准说明

混音 dB 层级与 LUFS 标准来自行业通行规范（EBU R128 衍生、播客/流媒体平台公开文档），属工程标准可直接引用；SFX 密度建议（≤8 处）为经验值，可按账号风格调整。
