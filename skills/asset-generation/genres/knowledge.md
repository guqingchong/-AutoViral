# 知识类 — 素材生成阶段专项指南

知识类内容的视觉核心是 **信息传递效率**。画面服务于理解——构图要干净、文字要清晰、流程要直观。视觉美感不应妨碍信息密度。

---

## 视觉风格方向

### 知识子类型与美学定位

| 子类型 | 美学参考 | 色调策略 | 构图要求 |
|--------|---------|---------|---------|
| 教程/步骤类 | 老爸测评, 李永乐 | 高亮度平光，白色/浅色背景 | 主体居中，步骤可视化，操作特写 |
| 产品测评 | 钟文泽, 李大锤 | 棚拍级布光，中性色背景 | 产品居中，45度角，微距细节特写 |
| 科普/知识 | 无穷小亮, 毕导 | 自然光或柔光箱，色彩鲜明 | 图文混排，标注箭头，对比构图 |
| 书单/推荐 | 都靓读书 | 暖色调，莫兰迪色系背景 | 书本平铺，封面特写，柔和光影 |
| 财经/数据 | 半佛仙人, 小Lin说 | 高对比深色背景，数据可视化 | 图表+人物双分屏，数据标注 |

### 知识类核心原则：可视化的信息层级

画面中的信息必须有清晰的视觉权重排序：

1. **主体**（人/产品/实验）—— 曝光最足，焦段最实
2. **操作/动作**（手的动作、产品功能演示）—— 必要时用特写或分镜强调
3. **辅助信息**（文字标注、箭头、图标）—— 使用 `poster_render.py` 叠加
4. **背景/环境**（书房、实验室、桌面）—— 干净整洁，避免视觉噪音

## 视频生成策略

知识类视频的运镜目标是 **帮助理解**，而非制造视觉冲击。

### 各子类型的视频策略

| 子类型 | 推荐方式 | 模型 | 提示词重点 |
|--------|---------|------|-----------|
| 手部操作教程 | `image2video` 首帧+微运动 | Seedance 2.0 | 微小动作，手部缓慢移动 |
| 产品展示 | `frames2video` 首尾帧环绕 | Seedance 2.0 | 产品缓慢旋转，背景干净 |
| 科普演示 | `image2video` 静态+元素动画 | 3.5pro | 仅有轻微必要的运动 |
| 数据解读 | 静态图+后期动效 | 不推荐 AI 视频 | 使用 After Effects 或剪映做图表动画 |

### 知识类视频限制

1. **避免用手部特写生成视频**——AI 视频生成目前对手指运动处理极差
2. **文字信息用后期叠加**——不要在 AI 生成阶段要求模型生成带文字的图像
3. **图表类内容建议不用 AI 视频**——用 Excel/Canva/Python matplotlib 生成图表素材后再剪辑

## 高清屏幕录制（替代 AI 生成）

软件操作类教程不必用 AI 生成视频。直接录制屏幕效果更好：

```bash
# macOS 自带录制
ffmpeg -f avfoundation -i "1" -t 30 -r 30 -c:v libx264 -preset ultrafast -crf 18 output.mp4

# Windows 录制
ffmpeg -f gdigrab -i desktop -t 30 -r 30 -c:v libx264 -preset ultrafast output.mp4
```

## 风格一致性指南

### 知识类必须统一的参数

| 参数 | 锁定方式 | 原因 |
|------|---------|------|
| **光线风格** | 同一教程系列使用完全相同的光线关键词 | 光线跳跃会分散注意力 |
| **背景** | 每张图的背景描述完全一致 | 让观众专注于内容而非环境变化 |
| **主体位置** | 人物/产品在画面中的位置保持一致 | 方便后期叠加文字标注 |
| **桌面/台面** | 使用相同色系的台面背景 | 产品测评中台面颜色是品牌感的一部分 |
| **文字配色** | `poster_render.py` 中标题/正文/标注使用配色一致 | 建立知识内容的视觉品牌识别 |

## 质量检查标准

### 知识类专属检查项

- [ ] 画面清晰度足够支持信息传递（教程步骤细节可辨认）
- [ ] 光线均匀，画面中没有因为背光/侧光造成的阴影遮挡
- [ ] 产品/主体对焦准确，边缘清晰无模糊
- [ ] 手部/手指在视频中没有扭曲变形
- [ ] 背景干净整洁，没有分散注意力的杂物
- [ ] 前后步骤的背景、光线、桌面材质一致
- [ ] 画面中没有无意义的装饰性元素

### 重新生成条件

| 问题 | 严重性 | 处理 |
|------|--------|------|
| 手部扭曲 | **致命** | 切换为静态图+后期标注，禁用视频生成 |
| 产品外观错误 | **致命** | 提供更精确的产品描述重生成 |
| 文字出现在画面中 | **严重** | 废弃该帧，在 prompt 中加 negative "no text" |
| 背景不一致 | **中等** | 统一背景关键词后重生成 |
| 光影不均匀 | **中等** | 调整光线描述为 evenly lit, shadow-free |

## 常见失败模式与修复

| 失败模式 | 现象 | 根因 | 修复 |
|---------|------|------|------|
| **手指变形** | 视频生成后手指数量不对或扭曲 | AI 视频对手部运动处理差 | 用静态图+剪映关键帧动画替代 |
| **产品幻觉** | 生成的产品实际不存在该型号 | 模型不认识具体产品型号 | prompt 中不要写型号，用外观描述替代 |
| **文字乱码** | 画面中出现无意义的文字 | AI 将文字当成视觉元素生成 | prompt 加 negative: no text |
| **光线跳跃** | 同一教程的不同步骤光线不同 | 光线关键词不一致 | 统一 light关键词，固定 seed |
| **背景干扰** | 画面中出现无关人物/物品 | 环境描述不够精确 | 明确 clean background, empty desk |
