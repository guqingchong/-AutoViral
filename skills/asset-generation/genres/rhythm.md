# 节奏类 — 素材生成阶段专项指南

节奏类内容的视觉核心是 **与音乐节拍的精确同步**。画面切换、运动节奏、色彩变化都必须与 BGM 的节拍/旋律对齐。

---

## 视觉风格方向

### 节奏子类型与美学定位

| 子类型 | 美学参考 | 色调策略 | 剪辑节奏 |
|--------|---------|---------|---------|
| 舞蹈/翻跳 | 1MILLION, 街舞挑战 | 高对比，舞台聚光/霓虹 | 同步节拍切镜，每4拍换镜头 |
| 卡点转场 | 燃烧的陀螺仪, 氛围感卡点 | 高饱和，色彩统一，对比强烈 | 每重拍切换场景/动作 |
| 音乐可视化 | Waveforms, 频谱动画 | 暗背景+霓虹/渐变色 | 形状/颜色随频率变化 |
| ASMR | 减压制作, 解压视频 | 柔光，高对比细节，微距 | 同步触发的视觉+听觉微互动 |
| 变速挑战 | 慢动作+突然加速 | 正常色温，高速摄影质感 | 慢动作铺陈→重拍加速 |

### 节奏类视觉铁律

1. **高对比**——每个画面必须有明确的视觉重心
2. **色彩冲击**——相邻两个画面的颜色对比要强烈
3. **运动方向一致**——卡点切换的前后两个镜头的运动方向要么相同，要么相反
4. **画面简洁**——每个画面只有一个视觉焦点

## 图片生成提示词模板

### 舞蹈场景模板

```
[质量前缀], full body shot of dancer in [服装], [舞蹈动作/pose],
[舞台/环境], dramatic stage lighting, [光线效果], high contrast,
fashion show lighting style, dance photography
```

### 卡点画面模板（按节奏烈度）

**强拍 (Downbeat) —— 视觉冲击最大：**
```
masterpiece, best quality, [主体], bold colors, strong contrast, dramatic lighting,
[颜色主调], impactful composition, high energy
```

**弱拍 (Off-beat) —— 视觉过渡/留白：**
```
masterpiece, best quality, [主体], soft lighting, muted tones, negative space,
minimal composition, breathing room, atmospheric
```

### 音乐可视化/频谱模板

```
[质量前缀], abstract visualization of [音乐风格/情绪],
[颜色方案], flowing shapes, [动态描述], dark background,
aesthetic music visualization, [风格关键词]
```

## 视频生成策略

### 推荐工作流：图片序列 + 后期卡点

**目前 AI 视频生成无法精确对齐音乐节拍。** 推荐以下工作流：

```
步骤 1: 按音乐节拍标记关键帧时间点（如每4拍一个关键帧）
步骤 2: 为每个关键点生成图片（openrouter_generate.py）
步骤 3: 用 image2video 为每张图生成短视频片段（2-4秒）
步骤 4: 在剪映/Premiere 中将片段对齐到节拍时间线
```

### 节奏类模型选择

| 需求 | 推荐 | 原因 |
|------|------|------|
| 舞蹈动作 | Seedance 2.0 | 动作生成更流畅 |
| 慢动作 | Seedance 2.0 | 支持精细运动细节 |
| 卡点转场 | 3.5pro | 场景转换更自然 |
| 音乐可视化 | 不推荐 AI 视频 | 使用 AE/剪映/Processing 渲染更精确 |
| 解压/ASMR | 3.5pro | 微距细节更好 |

## 风格一致性指南

### 节奏类视觉一致性

| 参数 | 要求 | 原因 |
|------|------|------|
| **人物一致** | 舞蹈视频全程同一 dancer | 翻跳视频本质是"一个人跳舞" |
| **颜色叙事** | 全视频有明确的颜色弧线 | 颜色变化本身就是节奏的视觉化 |
| **对比度等级** | 全视频保持一致的对比度水平 | 忽高忽低的对比度会打乱节奏感知 |
| **运动方向** | 统一设定每个镜头运动方向 | 运动方向的一致性增强视觉节奏 |

### 颜色切换策略（节奏类核心能力）

| 当前颜色 | 下一帧推荐颜色 | 效果 |
|---------|---------------|------|
| 红色 (#FF2C55) | 青色/蓝绿 | 抖音经典补色对，冲击力最强 |
| 暖黄/金色 | 冷蓝/深紫 | 温度感切换，情绪反差 |
| 黑/白 | 高饱和彩色 | 从极简到炸裂的开场效果 |
| 暗调 | 亮调 | 明暗节奏，蓄力→释放 |

## 质量检查标准

### 节奏类专属检查项

- [ ] 画面之间的颜色对比是否足够强烈
- [ ] 每个镜头的运动方向是否一致或符合设计规律
- [ ] 人物面部和肢体在舞蹈动作中没有扭曲变形
- [ ] 镜头的时长是否规则（每4拍/8拍等规律切换）
- [ ] 慢动作和正常速度的切换是否平滑
- [ ] 光线/色调在全片中的变化有逻辑

### 重新生成条件

| 问题 | 严重性 | 处理 |
|------|--------|------|
| 肢体扭曲 | **致命** | 降低动作幅度描述，或切换静态帧+后期 |
| 运动与节奏不匹配 | **严重** | 调整视频 prompt 的 energy 等级 |
| 颜色冲击不足 | **严重** | 在相邻帧 prompt 中明确指定补色关系 |
| 人物不一致 | **严重** | 使用 `--ref-image` 和 `--seed` 重生成 |
| 动作幅度太小 | **中等** | 加强 prompt 中 dynamic, energetic 等词 |

## 常见失败模式与修复

| 失败模式 | 现象 | 根因 | 修复 |
|---------|------|------|------|
| **肢体扭曲** | 舞蹈视频中手臂/腿扭曲 | 视频模型对复杂人体运动处理不足 | 缩短片段至2-3秒，减少动作幅度 |
| **节奏错位** | 画面运动节奏与音乐不符 | AI 视频无法感知音频节拍 | 使用图片序列+后期剪辑手动对齐 |
| **颜色平淡** | 卡点时颜色冲击不够 | 相邻帧 prompt 未指定对比色关系 | 明确写 `completely different color palette` |
| **运动方向混乱** | 每个镜头运动方向不同 | 未统一运动方向描述 | 全片使用统一方向描述 |
| **舞蹈无能量** | 跳舞看起来像在散步 | prompt 用了太温和的动作描述 | 用 `explosive, sharp, powerful, high-energy` |

## 节奏类 BGM 策略

| 子类型 | BGM 要求 | 生成提示词 |
|--------|---------|-----------|
| 舞蹈翻跳 | 强节拍，110-130 BPM | `upbeat pop, strong kick drum, 120 BPM, dance track` |
| 卡点视频 | 节奏变化丰富，drop 明显 | `electronic, build-up and drop, 128 BPM, dramatic transition` |
| ASMR | 无旋律，只有触发音质感 | `no melody, gentle tapping, fabric rustling, ear-level ASMR` |
| 慢动作 | 大气铺陈，后段爆发 | `cinematic orchestral build-up, slow start then dramatic crescendo` |

> **注意**：强烈推荐节奏类视频使用 `multimodal2video`（图+音频）让视频运动与音频波形对齐。
