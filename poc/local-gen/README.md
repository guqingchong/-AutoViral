## H3 选型记录

- 主模型：minimax_h3_fl2va_pruned_int8_convrot（T2V/I2V，19G，~20G 显存可入 24G 卡）

- 注意：pruned 版不兼容 Turbo LoRA 4 步加速（如需加速要换完整 int8 版 31G，磁盘不够）
