# 批量自动制作选项卡 · 用途驱动重设计方案

> 2026-08-18，回应用户反馈：批量制作选项卡设置不合理，覆盖不了主流短视频的内容样式、
> 风格塑造、素材来源；希望按**用途**组织选项。
> 调研依据：中国网络视听发展研究报告（2025）（知识科普类占比 28.5% 跃升第 6）、
> 巨量千川跑量素材 11 类公式、回形针等内容生产方法论。

## 一、现状问题

当前选项卡是**生产者视角**的技术参数平铺：内容类型/模板/数字人/时长/视频风格(8 种)/
素材形态/获取策略/成本档/配音。问题：

1. **没有用途入口**——用户想的是"我要涨粉/我要带货"，不是"素材形态选混剪还是轮播"
2. **选项间无联动**——选了"悬念揭秘"风格，时长/素材/配音不会跟着给出合理默认
3. **风格覆盖偏科**——8 种风格全是知识/观点类变体，缺测评、教程实操、清单干货、
   热点快讯等带货/引流主力形式
4. **风格与用途脱钩**——同一"知识科普"用于涨粉和用于带货，结构/钩子/CTA 完全不同

## 二、重设计：三层结构

### 第 1 层：用途（必选，决定一切默认值）

| 用途 | 目标 | 内容策略 | 默认形式组合 |
|---|---|---|---|
| 🚀 涨粉·打造 IP | 关注转化 | 系列化+强人设+信息增量 | 知识科普/行业洞察，3-5 分钟，动画讲解+实拍混剪 |
| 🛒 带货·促转化 | 点击/购买 | 信任构建+效果演示+利益点 | 测评/教程/好物分享，1-3 分钟，实拍为主+价格锚点卡 |
| 🔗 引流·导私域 | 私信/主页点击 | 强钩子+信息差+资料包诱导 | 悬念揭秘/清单干货，1-2 分钟，图文快闪+大字报 |
| 📢 品宣·扩曝光 | 播放/转发 | 情绪共鸣+热点借势 | 热点评述/情感共鸣，1-3 分钟，混剪+金句卡 |
| 📈 专业影响力 | 行业认可 | 深度解读+数据支撑 | 行业洞察/政策解读，3-7 分钟，数据图表+程序化动画 |

### 第 2 层：内容形式（随用途给推荐默认，可改）

对齐主流形式全集（当前 8 种扩到 12 种，按用途过滤展示）：

- 讲解类：知识科普(动画讲解)、行业洞察(数据图表)、政策解读(文件+动画)
- 观点类：观点输出(大字金句)、热点评述(快讯演播室)
- 带货类：测评对比、教程实操、好物清单
- 引流类：悬念揭秘、干货清单(图文快闪)
- 叙事类：故事叙述(分镜演绎)、情感共鸣(胶片质感)

### 第 3 层：参数微调（折叠高级，默认值由 1+2 层联动）

素材来源（素材库/AI 生成/精品混合/用户指定）、时长、配音音色、成本档、
数字人、模板、质量评审——全部保留但收进"高级选项"折叠区，默认值由用途×形式决定。

## 三、关键机制：用途 → 提示词注入

用途不只是 UI 分组，要注入 agent 的策划 prompt：
- 涨粉：结尾必带系列预告+关注引导；结构强调"信息增量密度"
- 带货：前 3s 痛点/价格钩子，中段效果演示，结尾 CTA+利益点重复
- 引流：钩子前置+关键信息留置不说完+主页/私信引导
- 品宣：情绪曲线优先，品牌露出时机控制
- 专业影响力：来源引用规范（回形针式"材料展示"），数据可查证

## 四、实施清单

1. `TOPIC_PURPOSES` 五用途定义 + 用途×形式 → 默认参数映射表（config 可配）
2. Topics.svelte 批量弹窗重构：用途卡片选择器（大按钮+图标）→ 形式下拉（按用途过滤）
   → 高级选项折叠区
3. 用途写入 works 表（新列 `purpose`），随 topicHint 注入 agent prompt
4. 评审标准按用途差异化（带货片重 CTA 检查，知识片重准确性检查）
5. 数据回流（P3-T4 已建）按用途×形式聚合三率，权重反哺选题排序

## 五、验收

- 五种用途各出 1 部片：结构/钩子/CTA 明显差异化
- 老用户无感迁移：不选用途 = 现有行为（高级选项全展开）
- 选项覆盖率：12 种形式 × 5 种用途矩阵可被完整表达
