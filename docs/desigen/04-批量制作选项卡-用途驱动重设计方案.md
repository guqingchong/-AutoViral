# 批量自动制作选项卡 · 用途驱动重设计方案

> 2026-08-18，回应用户反馈：批量制作选项卡设置不合理，覆盖不了主流短视频的内容样式、
> 风格塑造、素材来源；希望按**用途**组织选项。
> 调研依据：中国网络视听发展研究报告（2025）（知识科普类占比 28.5% 跃升第 6）、
> 巨量千川跑量素材 11 类公式、回形针等内容生产方法论。

## 一、现状问题

当前选项卡是**生产者视角**的技术参数平铺：内容类型/模板/数字人/时长/视频风格(8 种)/
素材形态/获取策略/成本档/配音。问题：

1. **没有用途入口**——用户想的是"我要涨粉/我要带货"，不是"素材形态选混剪还是轮播"
2. **选项间无联动**——选了"悬念揭秘"风格，时长/素材/配音不会跟着给出合理默认
3. **风格覆盖偏科**——8 种风格全是知识/观点类变体，缺测评、教程实操、清单干货、
   热点快讯等带货/引流主力形式
4. **风格与用途脱钩**——同一"知识科普"用于涨粉和用于带货，结构/钩子/CTA 完全不同

## 二、重设计：三层结构

### 第 1 层：用途（必选，决定一切默认值）

| 用途 | 目标 | 内容策略 | 默认形式组合 |
|---|---|---|---|
| 🚀 涨粉·打造 IP | 关注转化 | 系列化+强人设+信息增量 | 知识科普/行业洞察，3-5 分钟，动画讲解+实拍混剪 |
| 🛒 带货·促转化 | 点击/购买 | 信任构建+效果演示+利益点 | 测评/教程/好物分享，1-3 分钟，实拍为主+价格锚点卡 |
| 🔗 引流·导私域 | 私信/主页点击 | 强钩子+信息差+资料包诱导 | 悬念揭秘/清单干货，1-2 分钟，图文快闪+大字报 |
| 📢 品宣·扩曝光 | 播放/转发 | 情绪共鸣+热点借势 | 热点评述/情感共鸣，1-3 分钟，混剪+金句卡 |
| 📈 专业影响力 | 行业认可 | 深度解读+数据支撑 | 行业洞察/政策解读，3-7 分钟，数据图表+程序化动画 |
| 🎬 短剧制作 | 追剧/付费 | 钩子×反转×卡点，逐集留扣子 | 竖屏短剧，1-2 分钟/集，分幕剧本+角色一致性+AI 生成场景 |

**短剧制作的特殊性**（2025-2026 调研：微短剧爆款方法论）：
- 黄金结构：前 3 秒冲突锚定（捉奸/支票甩脸级强刺激）→ 30 秒情绪爆破 → 每集结尾留扣子逼看下一集
- 单集四拍：60-90 秒拆四拍，每拍只干一件事；"短剧不是把长剧压短，是把想追下去的理由塞进每集结尾"
- 角色系统：主角记忆点 = 反差设定 × 情绪杠杆；反派极致恶行+阶段性胜利
- 工程要求：分幕/分集管理、角色形象一致性（多集同人同脸）、卡点节奏标记
- 系六是六大用途中工程链路最长的：剧本（分幕大纲→单集脚本）→ 角色资产 → 逐集生成 → 合集管理

### 第 1.5 层：用途技能包（调研学习注入，本方案核心机制）

**每个用途配套一个"技能包"，由全网调研学习持续沉淀，非写死的 prompt 片段：**

1. **调研学习**：选中用途时（或点"更新技能包"），系统用 research 档模型+联网搜索
   调研该用途的最新爆款方法论（拆片公式/钩子库/结构模板/平台规则），
   蒸馏为技能条目存 `purpose_skills` 表（复用 template_skills 的调研-蒸馏-去重-权重模式）
2. **注入执行**：该用途的作品创建时，技能包随 prompt 注入 agent
   （如短剧用途注入"钩子×反转×卡点公式、四拍结构、角色反差公式"；
   带货用途注入"千川三段式、价格锚点话术、测评信任构建"）
3. **插件/工具映射**：用途还可声明需要的工具能力，系统自检并提示
   （短剧→角色一致性参考图管理；带货→商品信息卡；引流→主页链接卡；
   专业影响力→数据图表/code-scene 强化）
4. **数据回流转正**：P3-T4 的三率回流按用途聚合，表现差的技能条目降权、
   表现好的套路加权——技能包随实战持续进化，不是一次性 prompt

### 第 2 层：内容形式（随用途给推荐默认，可改）

对齐主流形式全集（当前 8 种扩到 13 种，按用途过滤展示）：

- 讲解类：知识科普(动画讲解)、行业洞察(数据图表)、政策解读(文件+动画)
- 观点类：观点输出(大字金句)、热点评述(快讯演播室)
- 带货类：测评对比、教程实操、好物清单
- 引流类：悬念揭秘、干货清单(图文快闪)
- 叙事类：故事叙述(分镜演绎)、情感共鸣(胶片质感)、**短剧分集(竖屏连续剧)**

### 第 3 层：参数微调（折叠高级，默认值由 1+2 层联动）

素材来源（素材库/AI 生成/精品混合/用户指定）、时长、配音音色、成本档、
数字人、模板、质量评审——全部保留但收进"高级选项"折叠区，默认值由用途×形式决定。

## 三、关键机制：用途 → 提示词注入

用途不只是 UI 分组，要注入 agent 的策划 prompt：
- 涨粉：结尾必带系列预告+关注引导；结构强调"信息增量密度"
- 带货：前 3s 痛点/价格钩子，中段效果演示，结尾 CTA+利益点重复
- 引流：钩子前置+关键信息留置不说完+主页/私信引导
- 品宣：情绪曲线优先，品牌露出时机控制
- 专业影响力：来源引用规范（回形针式"材料展示"），数据可查证

## 四、实施清单

1. `TOPIC_PURPOSES` 六用途定义 + 用途×形式 → 默认参数映射表（config 可配）
2. `purpose_skills` 表（migrate v26）+ 用途技能包调研服务（复用 template-research
   的调研-蒸馏-去重模式，research 档模型+Kimi $web_search）
3. Topics.svelte 批量弹窗重构：用途卡片选择器（大按钮+图标+"更新技能包"入口）
   → 形式下拉（按用途过滤）→ 高级选项折叠区
4. 用途写入 works 表（新列 `purpose`），技能包随 topicHint 注入 agent prompt
5. 短剧用途的工程扩展：分幕大纲→单集脚本的剧集管理（works 表 parent/episode 关联）、
   角色一致性参考图资产
6. 评审标准按用途差异化（带货片重 CTA 检查，知识片重准确性，短剧重钩子/卡点/留扣）
7. 数据回流（P3-T4 已建）按用途×形式聚合三率，权重反哺选题排序与技能包条目权重

## 五、验收

- 六种用途各出 1 部/1 集片：结构/钩子/CTA 明显差异化
- 每个用途技能包至少沉淀 5 条经调研蒸馏的技能，且能在出片 prompt 中观察到注入
- 短剧用途能产出 3 集连贯短剧（角色一致、每集留扣）
- 老用户无感迁移：不选用途 = 现有行为（高级选项全展开）
